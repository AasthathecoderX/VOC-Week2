# Major Project for Prompt Engineering:
 # "AI Assistant Development"

This is a simple AI Assistant web app built using Flask and integrated with the Groq API for conversational AI.
The assistant can perform multiple functions including answering questions, summarizing text, and generating creative content based on user prompts.

---

## 📚 Project Overview

The project is designed as part of an assignment for Vault of Codes. It showcases prompt engineering skills and AI integration by implementing an interactive assistant capable of:

    Answering factual questions

    Summarizing long texts

    Creating creative content like stories or poems


---

## ⚙️ Features

- Web-based user interface built using Flask with a simple chat-style interaction

- Multiple AI assistant functions selectable by the user

- User feedback mechanism for rating AI responses

- Groq API integration (can be switched to OpenAI API) for LLM-powered responses

- Structured chat display for user input and AI replies


---


## 🛠️ Tech Stack

| Layer         | Technology Used                                         |
|---------------|--------------------------------------------------------|
| 💻 Frontend   | HTML, CSS, Jinja2 Templating (Flask Templates)          |
| 🧪 Backend    | Python, Flask Framework                                 |
| 🤖 AI Chatbot | Groq API (LLM inference with models like llama3-70b)   |
| 🔐 Security   | Flask session management (basic auth/session handling) |

## 🚀 How to Run the Project

Follow these steps to set up and run the project locally:

### 1. Clone the Repository

```bash
https://github.com/AasthathecoderX/VOC-Week2
cd VOC-Week2
```

### 2. Create and Activate a Virtual Environment

**On macOS/Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**On Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```





### 3. Run the Application

```bash
python app.py
```

The application should now be running. Follow the console instructions or visit the localhost URL if using a web framework.
